# Asset provenance

All shipped visual assets are generated by the project's own `GardenArt` code at runtime. The moth, fireflies, thorn spirits, moonflower, leaves, ring, and gradient-star garden use original vector-like pixel drawing routines and a fixed project palette. No external image service, store asset, copied game sprite, or third-party art file is included.

All audio is synthesized locally at runtime by `MothlightGame`: an original harmonic ambient bed and short generated sine-sweep chimes. No external music or sound recording is included. Text uses the macOS system Avenir font when available, with Unity's built-in Arial fallback.
